📋 Problem Statement 4 Specification

The requirement requires two activities each having a separate button. Upon clicking on the button of first activity, second activity should open, and upon clicking on the button of second activity, first activity should be displayed.

  • ✔ FirstActivity: Contains button to trigger explicit intent targeting SecondActivity.class.
  • ✔ SecondActivity: Contains button to navigate back to FirstActivity.class.
  • ✔ AndroidManifest.xml: Both activities declared with correct launcher filter.

💡 Explicit Intent vs Implicit Intent

An Explicit Intent specifies the exact component to start by providing the target class name. The Android system immediately launches that specific component without querying other apps: 

// Activity 1 -> Activity 2
Intent intent = new Intent(FirstActivity.this, SecondActivity.class);
startActivity(intent);

// Activity 2 -> Activity 1
Intent returnIntent = new Intent(SecondActivity.this, FirstActivity.class);
returnIntent.addFlags(Intent.FLAG_ACTIVITY_CLEAR_TOP);
startActivity(returnIntent);
finish();

<activity
    android:name=".FirstActivity"
    android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent-filter>
</activity>
